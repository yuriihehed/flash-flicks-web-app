# FlashFlicks – Interactive Flashcard Web App

FlashFlicks is a web-based flashcard application built to help users study smarter. It offers customizable flashcards, multiple study modes, and a simple UI designed to keep learning focused and efficient.

 🚀 Features
- User authentication and session handling
- Create, edit, and organize flashcard decks
- Study with Learn Mode, Quiz Mode, or Timer Mode
- Responsive design using Bootstrap and custom CSS
- Forgot Password feature with reset UI
- Visual effects like animated thunder and custom icons

🛠️ Tech Stack
- **Frontend**: HTML, CSS (Bootstrap), JavaScript
- **Backend**: Django (Python)
- **Database**: SQLite (dev mode)
- **Version Control**: Git + GitHub

🎓 About the Project

This project was created by 6 passionate web developers eager to make the studying process more enjoyable and user-interactive. It was built as a final team project at DePaul University to demonstrate full-stack development, UI/UX design, and collaboration in a global software development environment.
